# ADR-0028：首屏拆棂观景窗 + 夜暖晕（去「铁窗感」二轮）

- 状态：已采纳（2026-10-02 作者两次反馈驱动）
- 关联：ADR-0027（整扇窗）、ADR-0024（被部分推翻：窗棂线索）、ADR-0021（单档五槽）、e72df81（接光一轮，被评「治标不治本」）

## 背景与证据

- 作者 2026-10-01：首屏「像关闭的铁窗，冷冰冰的，像监狱」。
- 一轮修复（e72df81）：框棂接光（sunlitFrame）+ 夜里窗台小灯（sillLamp）。实测棂面正午 `[123,127,143]→[182,177,175]`、深夜沉暗。
- 作者 2026-10-02 复评「不是很满意」，弹窗选择：**治标不治本 + 夜里还是冷/空**（未选「昏晨暗条」「说不清」）。
- 结构性根因：框棂占屏比 ~5%，接光改的只是细条颜色，整屏主色仍是窗外冷色；夜里暖载体（1px 棱线 + 22px 灯）存在感过弱。

## 裁决（作者选「拆棂观景窗+夜暖晕」）

1. **拆棂**：`WINDOW.MULLION / MULLION_X / TRANSOM_FRAC` 与 `WindowSpec.transomY / mullion / mullionX` 全部退役，横梃/竖梃不再绘制。玻璃连成整块，首屏读作「装在暖木框里的一整幅夜景」。
   - **推翻 ADR-0024 的「窗棂是最强的『这是窗』线索」**：「这是窗」的语法改由**框（18px 接光木框）+ 洞深阶梯 + 窗台（植物/小灯/月光带）**承担。
   - ADR-0027 的「整扇窗」语法不动：墙厚仍为 0、#window 仍零 DOM 内容。
2. **夜暖晕（glassWarm）**：夜里（与灯同门 `daylight < 0.22`）玻璃底部升起三段暖带（总高 ≈ 洞高 18%，alpha 0.10/0.06/0.03 向上递减，随夜深渐入），首屏夜色底部有「屋里的暖」。
3. **灯放大**：`SILL_LAMP` W 22→32、H 15→22、POOL 56→90，画法参数化（随常量缩放），亮缝位置 `slitY` 进返回值（绘制与 e2e 同源）。

## 判据

- 单测：`window-room.spec`（spec 无棂字段、WINDOW 无 MULLION 常量）；`window-light.spec`（glassWarm 三段贴底/无缝/alpha 上减/半程减半；sillLamp slitY）。
- e2e `world.spec`：旧棂位（0.52 洞高 / 0.38 洞宽，旧公式内联钉位）与紧邻玻璃同色（容差 18，任何棂色残留即爆）；深夜框内棱 1px 暖金 ≈ `lerp(accent,#fff,0.25)`、夜暖晕 R 抬升 ≥8（左 1/4 采样避开灯/植物）；白昼棱线与暖晕关门。

## 后记（2026-10-02 同日）

- **窗台小灯拆除**：作者复评「右下角的灯跟没有一样，很多余还抢镜头」→ `sillLamp`/`SILL_LAMP` 与绘制整体退役；夜暖晕保留并独立成门（`GLASS_WARM_DAY = 0.22`，原灯同门沿用）。窗台右段留空——克制优先。

## 后果

- 首屏「窗」的识别不再依赖分格；若未来觉得「太像画」，回滚点是恢复 MULLION 常量与 ⑦ 绘制段（git 历史 e72df81^..e72df81 有完整棂绘制）。
- 拆棂后玻璃高光斜带、内阴影、洞深阶梯不变——「玻璃物性」仍是窗读感的兜底。
