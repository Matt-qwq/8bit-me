# ADR-0025: hero 工位化——窗边的书桌与冷暖两光

日期：2026-09-26 状态：已定稿 关联：ADR-0020（窗外世界）、ADR-0021（天光房间）、ADR-0024（真窗化）

## 背景
真窗化（ADR-0024）落地后，hero 的老问题被放大：头像金框 + 按钮盒是一摞
「浮空的 UI 面板」，在「墙 + 窗」的房间语境里没有承托物，作者裁定
「无论放在哪里都很突兀，都不好放」，并定调：**只在意最终效果够不够精美
惊艳，不考虑工程量**。

## 决策：把 hero 变成「窗边真的有人在夜里干活」的工位
- **惊艳点的来源 = 两种光的对撞**：窗外冷月光（moonSpill/反光/霜，已有）
  × 桌上暖台灯（新增）。屋子从此有屋内的光源，不再是死墙。
- **几何单一数据源 = `src/lib/desk-room.ts` 的 `deskSpec(w,h)`**：地板线
  （floorY 835 + 1px 踢脚线）、书桌（右缘 = `win.x−frame−8`，不进洞；
  桌沿从窗几何派生 top=722、2px accent 受光顶缘全站同语言）、CRT
  （screen 176×156，装得下 AvatarSprite）、台灯（罩内 2px 亮缝 = 光源位）、
  茶杯（steam 几何）、书、三卡带锚点 cartXs。窄屏（w≤900）整体返 null。
- **canvas 静物 + 暖光**（BgFx.drawDeskRoom / T9）：桌/CRT 壳/灯体/茶/书
  同源派生色；灯池四层嵌套暖带（桌面近池 → 围板洗光 → 灯后墙光 → 地板
  光斑，呼吸 13.1s）、屏辉 2px 环、热气 3 列粒子。全部矩形阶带，无渐变。
- **DOM 上桌**（Hero.astro）：头像 SVG 原样保留，外层绝对定位逐边 0 差
  对齐 `crt.screen`；Press START 印在 CRT 下巴；三按钮变**桌上卡带**
  （x==cartXs、底边=桌沿、顶部 2px accent 受光带，仍是真 `<a>`）；
  标题/tagline/intro 变**贴墙铭牌**（无盒无框、1px 结构线下划线），右缘
  ≤ `win.x−frame`，intro 桌面 2 行。接线用 CSS 自定义属性，JS 只做
  模块→var 的搬运（零 CSS 几何常量）；`hero--desk/hero--stack` 两态，
  窄屏回退居中栈。
- **随世界淡出**：`--scene-a` 与 BgFx `worldAlpha` 同公式，滚动时 DOM
  工位与窗外世界一起淡；alpha<0.05 关点击。
- **不动**：typewriter 三行范围、文案一字不改（作者定稿口径）、
  AvatarSprite 生成逻辑、CSS 装饰层预算（canvas 自画）。

## 后果
- 测试口径三处有意变更（重排的一部分，非注水）：density 首屏内容改为
  「铭牌+头像+卡带」并集 bbox（0.19→0.15）；avatar 整数格断言移到窄屏档
  （工位屏内嵌不保整数格）；typewriter 零位移基线改「同页落定态」。
- e2e 新 8 条：hero-desk 5（对齐/卡带/文本缘/窄屏/反例自检）+
  world.spec 暖光 3（灯池「更亮且更暖」R−B 判据 / 屏辉 / 热气动+reduced 冻结）。
- 暖光与既有判据打架的坑已记录：地板光斑 α<0.09 时混色会撞进「CRT 屏色
  全画布独有」区间，故地板斑 α 抬到 0.11/0.09。
- 首屏叙事从「文字压风景」变成「夜里的一间屋」：窗是景，桌是生活。
