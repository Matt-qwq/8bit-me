# ADR-0022：hero 纸条化——大框退役，文字直接住进窗景

日期：2026-09-21 ｜ 状态：已实施（作者拍板「重新设计 hero」）

## 背景

窗外世界（ADR-0020）经四轮精化后，hero 的大实底卡（~896px 面板）成了画面中央
唯一的「死区」：作者反馈「整个 8bit-me 大框遮挡景色」，并指出这是**构图割裂**——
景和 hero 是两个世界。作者同时澄清：街机 title-screen 语言**不是**已确认的定稿，
定稿口径只有「像素风」。

## 否决的备选

- **玻璃卡**（面板 84% 半透明）：要重开 2026-09-10 打完的 AA 仗（当时实测无实心底
  h1 4.09 / tagline 3.41 / intro 3.10 破线），且景只是「幽灵程度」透出。否决。
- **无卡直坐 + 硬投影**：mock 实测亮模式下 dim 小字对比彻底破线、描边发糊。否决。
- **重新设计背景**（把景做淡迁就卡片）：推翻刚验收的场景精化投入。否决。

## 决定（两轮迭代后的定稿）：无底描边字

- hero 不再是面板：`.hero-inner` 去 `.pixel-panel`，左列纵向排布，**靠上对齐**——
  整列住在天空带内（山带 0.72h 起），不再压山。
- **文字完全裸坐景上，零底色零框**（作者对纸条形态的裁定：「文字带有底色，底下有框，
  更丑了」）。可读性载体 = 像素标题的正宗画法：**1px 八向描边 + 右下 2px 硬投影**，
  投影色 = `--c-panel`（永远与文字反极性：亮档白影托黑字、暗档黑影托亮字）。
- tagline / intro 从 dim 色提为 `--color-text`（dim 灰在亮天空上必破 AA，09-10 实测
  3.41；层级改由字号/字距承担）。kicker / 站况 / 实况保持 dim 丝印 + 描边。
- CTA 横排；窄屏（≤900px）居中。

### 否决的中间形态：错落纸条（notes）

第一版落地为「每内容块一条实底纸条」，作者看过即否——**纸条本质仍是「底色 + 框」**，
只是把一张大框换成多个小框，比大框更碎更丑。同一轮否决的还有玻璃卡（AA 契约要重打
且景只是幽灵程度透出）与无描边直坐（mock 实测 dim 灰破线、描边发糊）。

## AA 契约的迁移（不是放弃）

实心底的**根因**（文字可读性）不变，载体从「实底」改为「描边」：晨昏天空是中间亮度
（暮色紫 ~0.13–0.2），亮/黑两极文字**都**过不了 4.5——这正是所有像素游戏用描边字的
原因：可读性由描边承担，不靠场景底色。`hero-contrast` 的 worst-pixel 口径随之退役
（它把描边外圈的场景像素当背景，数学上永远覆盖不到描边的贡献），换成两层：
① **真渲染**——文字 rect 内 `--c-panel` 色像素占比 ≥ 阈值（描边真的画在像素上；
   h1 宽字距拉丁字 5%、CJK 行 8–12%，实测值向下取整）；
② 数学——文字 × 投影色 ≥ 4.5:1（`--c-panel` 与 themes.spec 的「正文坐面板」五槽
   保证同源；描边包住字形后，字与描边的对比就是可读性本体）。

## 守线迁移清单

| 测试 | 变更 |
|---|---|
| `hero-contrast.spec` 「坐在实心底上」 | 面板 alpha=1 → **h1/tagline/intro/status 各自 alpha=1** |
| `density.spec` 首屏面积 / P3-4 框里的东西 / V7 零重叠 | hero 退出面板口径（面积、填充率、右死区约束被纸条构图**有意打破**）；V7 的面板选择器改 `.hero-inner` |
| `bgfx.spec` canvas 亮度阶跃 | 采样窗移到 hero 左缘纯 canvas 区（x 24–264）——纸条硬投影边缘的混底差会污染旧窗 |
| `typewriter` 全链 | 不变（data-tw-line 三行、宿主 `.hero-text` 均未动） |

## 连带修复（本轮发现的两处测试债）

1. **近山 countColor 假红**：画法精化的山脚雾坡（MIST）把近山体逐行溶进天色后，
   纯色 `#3f6b5c` 在地平线以上已不存在——近山判据改「雾坡容差」（26/255，由雾坡
   上限 alpha × 通道差推导），雾坡几何提升为 `sky-scene.MIST` 常量供测试同源派生。
   同时修正雾坡方向 bug（原式在雾顶最浓，与「贴地平线最浓」的设计相反）。
2. **倒影 wobble e2e 的钟点 flake**：倒影不透明度随天色变，黄昏跑必然跌破阈值——
   测试钉正午时钟（与场景契约同一套 Date 覆写）。
