# ADR-0024: 窗外世界真窗化——嵌墙的窗、洞深与光交换

日期：2026-09-26 状态：已定稿 关联：ADR-0020（窗外世界）、ADR-0021（天光房间）

## 背景
窗外世界（ADR-0020）一直是**贴满屏幕的画**：天空/山湖铺满整个视口，窗框只是
贴在屏幕四边的装饰带，窗棂悬在半空。问题：①hero 面板与内容压在景色上，「窗」
名不副实；②屏幕边缘的框带让画面读作壁纸而非窗外；③没有洞深、没有光交换，
「玻璃」只有装饰性的斜高光。作者 2026-09-25 拍板做「真窗」：把景收进一面
**嵌在室内墙上的窗洞**里，让房间感落地。

## 决策（方案 A）
- **几何唯一数据源 = `src/lib/window-room.ts` 的 `windowSpec(w,h)`**：
  玻璃区占视口 ~52% 宽 × ~75% 高、靠右（1440×900 实测 576,81,756,675），
  带 `frame/sill/revealSteps/shadow/mullionX/transomY/wall` 全套字段；
  窄屏（w≤900）洞 84% 宽居中。所有取样/断言从它派生，禁止比例常数。
- **光学纯函数 = `src/lib/window-light.ts`**：`wallFace/wallLit/frameProfile`
  （墙与框的配色）、`moonSpill`（月光透窗：窗台 + 台体下墙面两段亮带）、
  `indoorReflection`（夜里玻璃上的室内反光斑，周期 ≥26s 慢漂）、`glassTint`
  （玻璃冷罩 alpha 0.04）、`frost`（寒夜 1px 霜线 + 角块）、`mistGlass`
  （雨 ≥0.85 起雾 ≤0.12）。零字面量色，只从 themes.ts 五槽 / sky 派生。
- **世界坐标搬进洞**（BgFx.astro）：`clip(玻璃区) + translate` 后全部场景
  （天体/云/山湖帧缓存/船鸟雾芦苇/倒影）按洞相对坐标绘制；land/sky 帧按
  `win.w+16` overscan 防视差露底。**天气粒子保持全屏坐标、只被洞裁剪**
  ——首页雨雪在洞内飘，无 world 的阅读页仍全屏飘。
- **窗体结构重写**（T4）：`drawWall`（墙面 + 室内灯带，灯带起点 = 实测
  nav 底，修复「整条被 sticky nav 盖住」）+ `drawWindowFrame` 窗体单元画法
  （框带只绕洞，不再满幅填充）+ **三面洞深阶梯**（`revealSteps=[5,4,3]`，
  贴玻璃最暗 → 洞缘与框同色）+ 框投景 8px 内阴影 + 窗台限窗体宽（台面
  受光 5px + 2px accent 受光线）。玻璃斜高光必须裁进洞内。
- **光交换接线**（T5）：洞内层序 = 冷罩 → 霜 → 起雾 → 滑痕水股 → 反光斑；
  洞外 = 框后月光带 → 窗台积水。夜里窗台有月光、玻璃有幽灵暖斑、寒夜有
  霜线；白昼全部归零（e2e 逐条守「白昼恒 0」防假绿）。
- **窗台陈设**（T6）：窗台左端一盆 6 矩形小盆栽（色从 `sky.ridgeNear` /
  frameProfile 派生），风 ≥0.2 时顶叶 ±1px 微摆，reduced-motion 恒静止，
  随窗颤一起动。
- **不做**：全高中竖梃（作者否决）；CSS 装饰层（canvas 内自画墙，不碰
  `body::before` 预算）；13 档主题复活。

## 后果
- 「8-bit 只是画、UI 回归细线」的边界未破：所有新元素在 canvas 里，CSS 零新增层。
- 洞外是「室内」：夜里月光带/反光/霜线只在洞缘，形成「房间里有灯、有人在」的暗示。
- e2e 新增 10 条（洞深阶梯 / 窄屏对称 / 月光带 / 反光斑 / 结露 / 冷罩 / 起雾 /
  灯带位置 / 植物 ×2），全部带「白昼或反例必红」的同源判据；触发表已更新。
- 中间态遗留（旧框带贴屏边、高光漏出）已随 T4 全部消灭。
- 字体子集随注释用字变化重跑过三次，`zpix.subset.woff2` 与源码字集同步。
