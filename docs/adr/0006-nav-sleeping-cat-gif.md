# 0006 - 导航睡猫改为固定色呼吸 GIF、删底部猫

## 状态
Accepted（2026-08-31，作者经 grilling 设计树收敛后拍板）

## 背景 / 问题

- 作者最初想「加一只猫在顶部、删底部的猫」并「加载所有猫动画」。经多轮盘问（grilling），
  三番修正后收敛为**最简形态**：只在 Nav 放一只**睡着的猫**，底部猫删掉，不做姿态轮播、不做猫群。
- 作者后来自行指定素材：`assets/r2nWTu.gif`，并明示「**改方案，我们只做猫睡觉的动画**」。
- 素材是**同一只三花猫**的 4 种睡姿横排（各 128px）+ 2 帧呼吸动画，带棕噪点卡底与浅色圆角框。

## 决策

- **Nav 猫** = `assets/r2nWTu.gif` 第 2 格（pose1：坐姿蜷尾、闭眼睡、露全脸）抠透明后的 GIF
  → `public/cats/nav_sleep.gif`（88×60、2 帧 500ms 呼吸循环），替换原 `kitten_sit.gif`，60px 角落吉祥物。
- **底部猫** = 删除 `Footer.astro` 的 `.cat-run` / `.track` / `kitten_sit2.gif` 及其 CSS（已验证无测试引用）。
- **演法** = 只做睡觉呼吸动画，**不做姿态轮播**。
- **抠图** = 边缘种子联通域取最大前景（猫主体），丢棕卡底 + 浅边框；色键单色抠不净（背景是噪点纹理），
  与 0005 交接文档记录的 kittens32 处理管线一致。

## 权衡（为何这样）

- **固定色 GIF vs 主题自适应 SVG**：GIF 位图猫是**固定配色，不随 13 套主题变**。
  备选是走回描 SVG（`CatSprite.astro` 用 `--gb-0..3` 随主题变），但那只能承载简单姿态、演不了
  这种丰富的呼吸动画。为「rich 动画」牺牲「主题自适应」——这是**真权衡**，且一旦固定难回退。
  → 未来读者看到导航里一只不随主题变色的彩色猫会疑惑，故记此 ADR。
- **单只睡猫 vs 姿态轮播 / 猫群**：轮播（sit/stand/walk 切换）虽丰富，但单只三花在同一素材里姿势有限，
  且角落小吉祥物不宜频繁硬切抢焦点；猫群则体积大、破坏本站克制美学，均被否决。

## 授权（知情覆写，同 ADR-0005 手法）

- 素材来自 itch.io（与 kittens32/Last tick 同风格、疑同包），**本机网络无法登录 itch.io 核实 license**
  （curl 失败）。作者已明确指定使用该素材，此决定按作者选择执行。
- 本 ADR 即为「记下裁决」：属**知情覆写**，非无知违规；若日后授权存疑，替换该 GIF 即可（单文件、低成本）。
