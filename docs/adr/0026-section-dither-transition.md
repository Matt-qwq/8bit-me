# ADR-0026: 章节切换·抖动溶解转场——把拜耳抖动从「景色画法」长成「章节交接画法」

日期：2026-09-26 状态：已定稿 关联：ADR-0017（hero 打字机）、ADR-0020（窗外世界）、
ADR-0021（天光房间）、ADR-0022（hero 铭牌）、ADR-0025（hero 工位化）
规格：`docs/specs/section-trans-v1.md`（作者 09-26 定稿；本文只记实现期决策与偏离）

## 背景
首页是一镜到底的五章滚动。跨页已有 CRT 光束（PageTrans，ADR-0002），章节标题已有
2px accent 受光带整齿扫入（A5），首屏有打字机（ADR-0017）——**章与章之间没有交接动作**：
滚动时两章硬切。作者定稿规格，要求用站内**已经在用的**像素语言补上这一笔：
把天空色带的拜耳抖动（`sky-palette` 的 BAYER4）升级成 8×8，做成「旧章从中心向外扩着
熄灭、新章从边缘向中心聚着点亮」的双向溶解。定位是**像素视觉语言，不是游戏场景手法**——
文档与实现里不出现「关卡 / scene wipe / FC」类表述。

## 决策
- **纯逻辑单住**：`src/lib/section-trans.ts`（零 DOM）——`BAYER8` / `threshold()` /
  `makeCeremony()` / `step()` / `alive()` / `shouldFire()`；`src/components/SectionFx.astro`
  只做滚动检测（rAF 节流比对 `offsetTop`）+ 放炮接线 + 绘制。**仅 index 挂载**
  （fixed canvas，z 90：盖 Nav 40 / SideDock 70，在 Konami 100 / CursorFx 110 之下；
  pointer-events:none，全程不劫持滚动、零布局位移）。
- **一条公式两个方向**：`v = (BAYER8/64)·DITHER_SPAN + |k|·波行程`，`k>0` 波行程 = 距离/射程
  （破·向外），`k<0` = 1−距离/射程（聚·向内）。格生命四态
  （破 0→1 闪→2 冷暗格；聚 2→1 闪→3 点亮），**闪只活 1 帧**。
- **仪式梯度**：首次 hero→about = 破 240ms + 聚 360ms + 2px accent 光束整齿横扫一次
  （复用 REVEAL 的扫入语言）；其后只留「呼吸」（仅聚 300ms）。同章不重放、间隔 ≥900ms、
  快速连滚只给最新目标一炮（取消进行中一场 + 挂起最新目标）、reduced 恒不放炮。
- **覆盖区域跟着滚动**：绘制时按**实时**的「from 章可见带 ∪ to 章可见带」裁剪，
  波心取放炮那一刻两章可见带的中心、起源线 = 章节边界的真实视口 y——仪式长在滚动上，
  不是全屏假覆盖。

## 实现期偏离规格的三处（都属规格 §7 授权的「开放旋钮 / 实现时校准」）
0. **几何与进度都长在滚动上**（作者 09-26 复审：「显然跟计划里描述的不一样」→ 修复）：
   第一版把波心/起源线**冻结在放炮那一刻的屏幕坐标**上，页面继续滚它就飘在原地，
   看起来是「屏幕上浮着一个抖动圆斑」，而不是章节在滚过去时溶解——直接违反 §2
   「起源线 = 章节边界扫过视口的**真实** y … 与滚动同一物理」。现在：
   - 每帧 `reanchor(state, rects)`：波心 = 两章**当前**可见带的中心，起源线 = 边界
     **当前**视口 y（光束跟着边界走）；格状态只朝前走，不因波心移动而闪回。
   - 进度 = 时间项 + 滚动项（`|Δscroll| / SCROLL_SWEEP_PX × 总时长`，单帧封顶
     `SCROLL_BOOST_CAP_PX`）：快滚被压缩（滚动抢跑完），慢滚/停住由时间项兑底
     （整场仍 ≤750ms）；封顶保证「一帧跳几百像素」不会把整场仪式直接跳过去。
1. **阈值归一化**（公式形状不变，分母与系数校准）：规格原式 `bayer/64 + k·d/对角线`
   直接实现会**烂尾**——拜耳项自身就占满 [0,1)，远心格必然撞顶钳到 1，在 progress=1
   同一帧爆开（收尾硬切）；聚方向更糟，远心格一开场就全亮。改为：
   - 距离除以**射程**（波心到格网四角的最远距离，不是整幅对角线——波心常在带中心）；
   - 拜耳项乘 `DITHER_SPAN`、斜率取 `1−DITHER_SPAN`，两者和恒 ≤1
     （0.55·63/64 + 0.45 = 0.991）。
   **`DITHER_SPAN` 必须让拜耳项主导**（0.55）：它占满 0..1 时全区域都是抖动的密度场
   （真溶解，波前是密度梯度）；压到 0.25 会退化成「实心色块 + 抖边」的擦除——
   第一版就是这么调的，看图才发现那就不叫「抖动溶解」了。
2. **格本体对比度校准**：规格给 `lerpHex(bg, text, 0.35)` / `lerpHex(bg, accent, 0.35)`。
   在恒暗档（bg `#0b102c`）上实测对底 2.87:1，整屏读作**亮灰闪**，与规格自己的用词
   （「熄灭」「冷暗脉」）相反。收到 `BODY_MIX = 0.26`（对底 2.11:1、对暗面板 1.53:1）：
   仍读得出抖动图案（1 帧亮闪把波前勾出来），但整屏是「暗下去」不是「闪一下」。
   另加 `WARM_UP = 0.4`：破→聚 的格本体在聚阶段前 40% 内由冷暗渐变到暖暗——
   不做的话整屏一帧换色，读作「闪了两下」而不是一次溶解。

## 后果
- 新单测 36 条（`tests/unit/section-trans.spec.ts`）：方向性（同相位格比距离 +
  破近心已切/远心未动、聚反向）、无撞顶（整幅 max v < 1）、签名确定性、几何整数格、
  闪只活 1 步、有限步收敛（≤750ms）、**滚动联动（重锚只动几何不动格状态 / 滚动项推进 /
  单帧封顶不跳场 / 连续大滚动仍收敛）**、放炮节流矩阵、源码契约（lib 零 DOM / 仅 index
  挂载 / z 90 / 不劫持滚动）。
- 新 e2e 8 条（`tests/e2e/section-trans.spec.ts`）：只挂首页、加载零炮、跨章出格网且逐帧在变、
  首次双阶段破聚两色可辨（取 computedStyle 的 `--c-text`/`--c-accent`）、仪式中滚动继续前进、
  零布局位移（用 offsetTop 链量，transform 不算）、同章不重放、reduced 零像素。
- **反例自检已跑**：注释掉 `step()` 的时间推进 → 方向性与收敛用例 8 条全红，还原后全绿。
- 触发表新增一行（开发流程文档）；术语进 CONTEXT.md。调参只动 `SECTION_TRANS` 常量区，
  阈值公式形状与色彩语义不动。
