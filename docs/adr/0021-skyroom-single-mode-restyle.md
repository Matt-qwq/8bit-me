# ADR-0021：13 套 GB 主题 → 「天光房间」单身份双档（2026-09-22）

## 状态

Accepted（作者 2026-09-22 拍板「开始吧」；三条前置裁决由作者同日给出）

## 背景

ADR-0020 落了「窗外世界」（sky-palette 8 关键帧 + 真实晨昏 + 天气）之后，作者看图指出：**背景与整站不是一体**。复查截图确认三层断裂：

1. **亮度悬崖**：首屏是明亮天空，第二屏起跌进近黑的暗房（72% scrim 压 `#0e1526`）——「窗外是白天，房间里是深夜」。
2. **两套视觉语法**：天空讲「色带 + 拜耳抖动 + 大气透视 + 剖面窗框」；站内 UI 讲「PCB 斜网格 + 冲压铭牌（4px 硬边 + 焊盘）+ 街机高饱和 accent」。无共同语言。
3. **天空调色板离开首屏就死了**：全站最好看的一套颜色只活在第一屏。

作者的三条裁决（2026-09-22）：

1. 「现在的主题和主题色与背景**没有任何关联**」→ 颜色必须与窗外同源。
2. 「不需要 13 套主题，**1 套主题深色浅色能切换就够了**」→ 主题系统收缩。
3. 「CRT 把颜色遮挡了」「8bit 不需要遵循了，这个主体对 AI 不友好」→ CRT 常驻层退役，8-bit **机制约束**（四色槽位、线宽白名单、像素对格纪律）解除。

## 决策

### 1. 主题 = 1 套身份 × 明暗两档，色值从天空采样（同源）

`themes.ts` 重写为 `MODES = [LIGHT, DARK]`，五槽按角色命名：`bg / panel / line / accent / text`。

| 槽 | LIGHT（白昼房间） | DARK（夜晚房间） | 采样出处（sky-palette） |
|---|---|---|---|
| bg | `#edf4fb` 纸白 | `#0b102c` 夜空 | 昼空最亮带 / 夜空色带（alt=-0.35 帧 bands[1]） |
| panel | `#fbfdff` 云白 | `#202a5e` 室内一档 | cloudHi / bands[4] 收敛 |
| line | `#b9cde4` | `#39437a` | 大气透视的「地平线」 |
| accent | `#2f6cc0` 昼空蓝 | `#ffd27a` 窗灯金 | alt=0.55 帧 bands[0] / `windowLit` |
| text | `#16263f` 深夜蓝 | `#e8ecf5` 月光 | 夜空顶带 / `moon` |

要点：**夜里唯一的暖色 = 窗外人家亮着的那盏灯**（windowLit）——暗档的强调色不是新发明的颜色，是窗外世界本来就有的颜色。CSS 变量从 `--gb-0..3` 更名为 `--c-bg/panel/line/accent/text`（语义槽，不再是 Game Boy 槽位）。

### 2. 跟随太阳（mode.ts）

- 三档偏好：`8bitme:mode` = `auto`（默认）/ `light` / `dark`（SideDock 开关循环）。
- auto = `modeFromSunAlt(sunAlt)`：分界取暮光边缘 **-0.04**（与 sky-time 的 daylight 起点同源）。BgFx 每分钟用真实 anchors 喂一次 `syncAutoMode`——**窗外入夜，房间也入夜**。
- 首帧前 BaseLayout 用钟点近似（7:00–18:30）防 FOUC；BgFx 加载后立即纠正。

### 3. CRT / 机制约束退役

- 删：`CrtScanlines` 组件（文件留占位待作者手工删）、`--crt-scan/--crt-vignette`、`body::before` 的 45° PCB 斜网格、`.pp-pad` 四角焊盘（BaseLayout 注入脚本、index 点亮逻辑、全部相关断言）、13 套主题面板、`--ls-*` 之外的线宽四档白名单纪律。
- **保留**：CRT 光束**转场**（PageTrans，瞬时开机仪式不遮色；幕布改固定深蓝 `#05081a`，两档模式下「关机」都是黑屏读感）；Zpix 标识字段；像素滚动条；`?show` 仪式。
- 装饰层从 2 层（斜网格 + 扫描线）减到 **1 层**：墙面水平色带（echo 天空色带语法，`--wall-band` = text 槽 4%，对底 ≤1.2:1）。
- SFX：`select` 角色（主题选择 arp）随主题面板退役，剩 nav/click/toggle/game/hover 五角色。

### 4. 面板新语言：「受光面」

`.pixel-panel` = 1px 地平线描边 + 面板底（受光面）+ 顶缘 **2px accent 受光带**（每张卡自己的一条日出线）+ 2px 硬边落影（剪影层）。按钮/标签/封面同族收紧到 1px 线。排版体系（Zpix 标识 + 系统黑体正文 + 字号阶梯）不动。

### 5. /lab 图册

皮肤（`scripts/atlas/skin.mjs`）从 13 块主题派生改为 2 块模式派生（archify token 名不变），两张产物（warehouse-layers / rpa-migration）已用 archify 重建并提交；引导脚本默认档 `gb=dark`；单测/e2e 全部改钉两档。

## 后果

- 正面：窗外窗内同源同律；对比度底线（正文 ≥4.5、强调 ≥3、面板/线可辨）由 `themes.spec.ts` 数学锁死；主题切换 UI 从「13 格画板」变成一个三档开关；测试面砍掉约 60 条主题机相关断言。
- 代价：13 套主题的「换肤」乐趣退役（历史见 git）；浅色档是全新 surfaces，需在真实观感上再走一轮验收矩阵。
- 备忘：`tests/unit/texture-budget.spec.ts`、`line-hierarchy.spec.ts`、`themes.spec.ts` 已重写为 ADR-0021 口径；`docs/specs/line-hierarchy.md` 标记退役。

## 与作者裁决的对应

| 作者原话 | 落点 |
|---|---|
| 主题与背景无关联 | §1 色值全部采样自 sky-palette，测试锁「同源性」 |

## 附录：LIGHT 档退役（2026-09-23 作者裁决：「不要浅色主题了」）

- **站点恒暗**：LIGHT 档（白昼房间）退役，`themes.ts` 只剩 DARK（夜晚房间）。「天光房间」的叙事保留一半——颜色仍采样自窗外天空（夜空/月光/窗灯金），但「房间跟着太阳换昼/夜」退役：**UI 不再跟太阳，窗外照常跟**（sky-time / sky-scene 一字未动，晨昏与天气照旧）。
- **整套机制一并退役**：`src/lib/mode.ts` 删除（三档开关/跟随太阳/钟点近似/防闪档预挂载）；`html[data-mode]` 属性消失（`:root` 直接注入暗色五槽）；SideDock 的 AUTO/LIGHT/DARK 开关按钮移除；`8bitme:mode` 偏好键废弃（旧存档被静默无视）；切档眨眼动画（theme-flash）退役；`/lab` 皮肤单档（MODES=[DARK] 派生，产物已重建）。
- **守线变化**：`themes.spec.ts` 改单档契约（五槽对比度/天空同源性不变，只对 DARK 断言）；e2e 的「三档模式」「主题跟随」类用例删除或改恒暗断言；`8bitme:mode`/`data-mode` 在 tests 全量清零。
- 教训：与雷声同一天的两条裁决——**拟真推演救不了「不想要」**。跟随太阳是我在推演「像真房间」，但作者要的是恒定的夜。窗外世界跟太阳是**景**（保留），UI 跟太阳是**开关**（退役）。
