## 怎么验

`npm run dev` → http://localhost:4321。**点亮仪式新标签页才播**（sessionStorage `8bitme:boot`，
刷新不重播；想再看：新开标签页、地址后加 `?show`，或 DevTools → Application → Session Storage 删掉该键）。
**想看某个时刻/天气**：改系统时间到黄昏、或用 DevTools 断网看降级为晴的画面。

## 亲验矩阵

### 窗外世界（world，默认，2026-09-21 / ADR-0020）

| 场景 | 看什么 | 预期 |
|---|---|---|
| 新标签页打开 `/` | 点亮仪式 | 世界从深夜快进到当前时刻（~1.6s）后落到稳态 |
| 对照窗外真实时刻 | 晨昏 | 白天/黄昏/夜晚与此刻一致；**日落前后最华丽**（整片湖是金红的） |
| 下雨 / 下雪的日子 | 天气 | 雨丝 + 湖面涟漪；雪花 + **山脊积雪**；云厚时太阳被遮 |
| 滚到第二屏 | 世界退场 | 天空淡出回主题底色（「房间」）；**雨雪仍飘**（阅读页也下） |
| 切到 `core` / `off` 档 | 三档 | core = 原机器叙事；off = 纯主题底色 |
| 浅色主题 × 雨天 | 摩尔纹 | 湖面水平条纹与垂直扫描线是否打架（**已知未结**，见 ADR-0020） |

### 机箱内部（core 档，v5 原样）

| 场景 | 看什么 | 预期 |
|---|---|---|
| 新标签页打开 `/` | 开机仪式 | 芯片走线从主芯向外级联点亮（~1s）+ 右上角 LED 双闪，然后回落为暗结构 |
| 静置 10s | 默认静 | 结构层（走线/芯片）恒在；最多偶遇一只信号包沿走线流动（6-12s）或一颗尘埃（15-25s） |
| 右上角 | 待机灯 | 3×3px LED 呼吸（1.6s），「机器活着」的锚点 |
| 点击页面任一交互 | click 响应 | 点击处方括号 reticle 快闪 + 最近走线一只信号包回传芯片（「键被机器收下」） |
| 点导航/锚点 | nav 响应 | 2 只信号包向芯片汇聚（收下输入） |
| 悬停按钮/链接 | hover 响应 | 指针 80px 内走线微亮（近场照明，零新粒子） |
| Konami ↑↑↓↓←→←→BA | 彩蛋联动 | 背景全部走线短暂满亮 ~1.5s（前景爆裂照旧） |
| 切换主题 | 磷光再调谐 | 走线短促增亮 0.4s 后以 steps 衰减回地板，颜色随主题换 |
| 往下滚 / blog 页 | 可读性 | 结构线被 scrim 压暗后仍可辨，文字不抢 |
| 浅色主题（nes-punch/inkpaper） | 防洗白 | source-over 门控，结构层变「浅色电路板」读感，不糊 |

### 模式循环（侧边仓 ✦：WORLD→CORE→OFF）

| 档 | 复核点 |
|---|---|
| WORLD | 窗外世界 + 天气 + 晨昏（默认） |
| CORE | 机器叙事全套件（v5 原样，不回归） |
| OFF | 全静，按钮态正确 |
| 刷新 | 记住所选档（`8bitme:bgfx`；旧档 stars/rain/… 自动归一到 WORLD） |

### 主题抽查

- [ ] ③ 深色 ×2 用于 additive 辉光在场；浅色 ×2 防洗白；切换过程经「磷光再调谐」无杂音。
  **world 档下主题不影响天空**（窗外是实景，不参与 13 套主题）——切换主题时只有「窗内」变

### 铁律三问（world 档，2026-09-21）

- [ ] ⑤ **装饰层预算**：world 没有新增 DOM 装饰层（世界全画在既有的 `-3` 层 canvas 里），
  全站常驻装饰层仍是网格 + 扫描线 **2 层**
- [ ] ⑥ **移除后仍有结构感**：切到 `off` 档，UI 的层级、分隔、可读性**一字不变**
  （世界是背景风景，不承载任何分隔/引导/位置/状态语义）

### 无障碍抽查

- [ ] ④ 系统「减弱动态效果」：core 事件层降频但仍可辨（结构层恒静不受影响）；
  **world 档**：点亮仪式直接跳过、芦苇摆动幅度降到 35%、**雷闪禁用**（WCAG 2.3.1）

- 全绿 → commit 已可交付（v5 已入库）→ 作者拍板部署（现行主通道 `bash scripts/deploy-pages.sh`，ADR-0010；`部署脚本` 为备用）
