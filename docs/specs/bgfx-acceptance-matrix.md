## 评审门 5 条（v5 设计约束，肉眼复核）

- [ ] ① **单强调色**：每一帧唯一的「活色」是 --gb-2；结构层（走线/芯片/尘埃）灰阶派生，无第 5 色
- [ ] ② **编排主角**：任意 10s 窗口只有一个焦点动作（信号包 / 开机仪式 / 交互响应其一），其余压到极低
- [ ] ③ **静置密度**：静置时移动对象 ≤4（一台机器开着、没人在操作）
- [ ] ④ **时长档**：交互响应 ≤300ms、开机仪式/信号包 1-2s deliberate
- [ ] ⑤ **停帧构图**：DevTools Performance 里 pause 一帧——冻住的画面是一张 PCB 设计图，而非噪声场

## 亲验矩阵

### 核心：机箱内部（core 默认）

| 场景 | 看什么 | 预期 |
|---|---|---|
| 新标签页打开 `/` | 开机仪式 | 芯片走线从主芯向外级联点亮（~1s）+ 右上角 LED 双闪，然后回落为暗结构 |
| 静置 10s | 默认静 | 结构层（走线/芯片）恒在；最多偶遇一只信号包沿走线流动（6-12s）或一颗尘埃（15-25s） |
| 右上角 | 待机灯 | 3×3px LED 呼吸（1.6s），「机器活着」的锚点 |
| 点击页面任一交互 | click 响应 | 点击处方括号 reticle 快闪 + 最近走线一只信号包回传芯片（「键被机器收下」） |
| 点导航/锚点 | nav 响应 | 2 只信号包向芯片汇聚（收下输入） |
| 悬停按钮/链接 | hover 响应 | 指针 80px 内走线微亮（近场照明，零新粒子） |
| Konami ↑↑↓↓←→←→BA | 彩蛋联动 | 背景全部走线短暂满亮 ~1.5s（前景爆裂照旧） |
| 切换主题 | 磷光再调谐 | 走线短促增亮 0.4s 后以 steps 衰减回地板，颜色随主题换 |
| 往下滚 / blog 页 | 可读性 | 结构线被 scrim 压暗后仍可辨，文字不抢 |
| 浅色主题（nes-punch/inkpaper） | 防洗白 | source-over 门控，结构层变「浅色电路板」读感，不糊 |

### 六模式人工覆盖（循环按钮 ✦：CORE→STARS→SCAN→RAIN→WAVE→GRID→OFF）

| 模式 | 复核点 |
|---|---|
| STARS | 滚动视差依旧（近层 22% 页速漂移） |
| SCAN | 细带淡尾、阅读页友好 |
| RAIN / WAVE / GRID | v4 原样，不回归 |
| OFF | 全静，按钮态正确 |
| 刷新 | 记住所选模式（`8bitme:bgfx`） |

### 主题抽查

- [ ] 深色 ×2 用于 additive 辉光在场；浅色 ×2 防洗白；切换过程经「磷光再调谐」无杂音

### 无障碍抽查

- [ ] 系统「减弱动态效果」：core 事件层降频但仍可辨（结构层恒静不受影响），开机仪式可跳过性可接受
