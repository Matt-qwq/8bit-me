没有文档的系统怎么破：一套黑盒逆向打法

2026-08-29·逆向工程HAR自动化方法论

复盘整理：无文档系统对接与逆向实践，本文整理于 2026-08。

很多内部业务系统没有文档、没有 SDK，连后端权限都没有。你能用的只有浏览器， 外加一个能打开的页面。传统自动化平台的录屏点击能跑通 demo，但界面一变就死； 一页页点下去，又慢又脆。

换一条路：直接走协议层，把黑盒变成「能写、能验、可复用」的体系。 这套打法的骨架是方法论降维：大问题拆成可验证的小步，每步给出纪律。

正文四段：先走四步打法，再破加密这道门，随后收产物闭环，末段画安全边界。

被否的路：录屏点击 —— 界面一变就死

一、拆黑盒：四步可验证打法

点页面只能证明它跑得动，证明不了它为什么这么跑。顺序是先解剖，后点击， 前一步的猜测，由后一步的实证校验。

第一步：静态先行

先把表单页的前端 JS 存下来，交给 JS 静态分析器解剖。DevTools 导出的脚本 动辄数千行，正好喂给机器慢慢读。解剖一次能抽出九类结构信息， 头五类回答「系统长什么样」：

  • 字段控件：表单里有哪些输入。
  • 联动规则：字段之间怎么联动。
  • 内联字典：key 到文本的映射。
  • 请求封装：对外请求怎么包。
  • API 调用清单：系统暴露了哪些接口。

剩下的四类，回答「操作会走到哪」：

  • 保存链：从操作到请求封装的调用图，含固定注入字段。
  • 校验逻辑：提交前有哪些规则。
  • 事件绑定：页面上挂了哪些监听。
  • DOM id 规律：定位时能复用的锚。

这一步的产出是结构骨架：哪些字段、哪些接口、保存时谁带了谁。信息不对 没关系，运行时验证与 HAR 对账会回来校验。

第二步：运行时验证

骨架里最缺的是动态参数与编码映射，它们只存在于运行时。做法是注入双层 hook（钩子，在调用点拦截观察）。

业务层挂请求封装对象，拿到带业务语义的服务、动作与请求体。网络层挂 XHR（XMLHttpRequest），拿到全量 URL 与原始文本，包括字典文件。

探针窗口很短：先注入再操作，刷新即失效。于是设计成页面加载前注入， 操作完整体导出。导出物里，字典的 key 到文本映射，是编码翻译的权威来源。

第三步：HAR 对账

把操作过程抓到的全量流量，导出成 HAR（HTTP Archive，真实流量记录）。 分析器拿到 HAR 做四件事：

  • 按请求参数分组接口。
  • 提取接口 schema。
  • 比对骨架与运行时的差异。
  • 列出副作用接口清单。

铁律一条：HAR 是唯一事实源，编码翻译禁止猜测。猜过一次，错一整批映射， 从此立规。同一接口带不同标志位，返回形态可能完全不同，必须按真实形态分析。

第四步：视觉兜底

截图、票据、报错图这类信息走不到协议层，交给本地视觉。逐字精确用本地 OCR（光学字符识别），语义理解用本地视觉模型。原则是先本地后外发： 数据不出内网是底线，不是为了省钱。

协议与页面都摸清了，剩下的门常在前端加密参数上。

二、加密三板斧：diff、识别与定位

黑盒系统里最常见的「最后一道门」，是前端加密参数。打法三板斧，一斧接一斧。

第一板斧是 diff（差异比对）：相邻两次请求并排，找出动态变化的加密参数。

第二板斧是识别：参数属于 RSA（非对称加密）、消息摘要还是验证码。 RSA 的公钥，通常来自服务端下发的 challenge（质询值）。

第三板斧是定位：导出一段 CPU profile（性能采样记录），沿调用链在源码里 找到加密函数。前端加密最终一定在某份 JS 里以明文躺着，这是定位能成的根因。

三、产物闭环：报告加反查

方法论不产出一次性脚本，就白做了。每个解剖过的页面，都落一份解剖报告。 报告先记六类信息：

  • 字段：系统里有哪些输入。
  • 联动规则：字段间怎么联动。
  • 字典：key 到文本的映射。
  • 保存链：操作到请求的调用图。
  • API 清单：接口及其参数形态。
  • 校验逻辑：提交前的规则。

报告分两版：markdown 给人读，JSON 给脚本自动化对接。

写入后的验收，走「保存后反查」纪律。编码字段按 key 比对，因为文本跨接口不稳定。 编码值要么从字典直取，要么取自源码内联字典，两边互相对账。

四、安全边界：授权是前提

这套打法有前提：只处理自己工作范围内、得到授权的系统。全程守住数据不出 内网：内网素材最小摘取，脱敏后才外发。逆向的对象是格式与协议，不是绕过 安全控制。

收尾：把黑盒变成一份报告

「没有文档的系统」在政企内部生态里是常态，不是意外。这套打法的价值， 是把个人经验固化成团队可复用的工具链。

四层走完，任何黑盒都只是一份等待解剖的报告，而不是只能靠人力点击的谜。 到这一步，「能看能点」才真正换成了「能写、能验」。
