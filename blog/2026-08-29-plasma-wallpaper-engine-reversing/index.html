给 KDE 写一个 Wallpaper Engine 兼容层：逆向、渲染与百余条教训

2026-08-29·C++QtKDE逆向工程project walkthrough

复盘整理：plasma 逆向工程完成于 2026-07 至 08 月，本文整理于 2026-08。

KDE 桌面没有官方视频壁纸能力。Steam 创意工坊里，Wallpaper Engine（下称 WE） 攒下了成体系的壁纸生态。视频、网页与实时渲染场景，三类都全。

这篇复盘的主角是一个 Plasma 6 壁纸插件。它不调用 WE 的运行时，而是从 byte-level（字节级）开始逆向壁纸格式。这样 KDE 就能原生消费合法的 创意工坊内容。一句纲领立住全文：逆向兼容不是偷代码，是读懂格式后做 自己的实现。

正文走六段：先是三条管线，再是 Scene 容器逆向。随后是像素对质、平台共存 与 bundle 契约，末段收进笔记习惯。

一、搭三条独立渲染管线

插件按壁纸类型搭管线，三类素材各走一条。视频线看似简单，难点全在「无缝」。

无缝来自素材元数据的精确处理。循环接缝留半帧不行，多一帧也不行。

网页壁纸走 QtWebEngine 渲染，三条线里它的硬约束最重，细节放到平台一节。 场景壁纸最硬核，走自研 C++ 渲染引擎。引擎直接挂 Qt Quick 的 QSGRenderNode，逐对象复现 WE 的场景描述。

壁纸类型定了，真正的硬仗在 Scene 那一包私有数据上。

二、拆 Scene 的私有容器

WE 的场景包是私有容器格式，从壳体到纹理全是黑的。引擎要吃进这份数据， 得先拆开五道门。

PKGV 容器双格式

早期结构靠开源解析项目 repkg 确认。再往后发现，同一容器其实有两代格式： 版本 0005 与 0021。两代各配一套解析策略，固定偏移与魔数扫描双轨并行。

纹理三级封装

容器里的纹理走三级封装链：TEXV0005 → TEXI → TEXB。解码分两步，先 LZ4 解压，再做 BCn（BC3/BC1）解码。BC3 纹理偶尔短缺，解码器会按实际高度 自适应解码。官方数据偶尔不自重，解码器得比官方更宽容。

名字链追踪

模型引用哪张材质、材质又引用哪张纹理，原生格式不直接给答案。只能靠 model → material → .tex 的名字链逐级解析出来。

像素区里抠 MP4

部分场景把 MP4 藏在纹理的像素区域里。提取器逐字节扫 TEXV 像素区， 把 MP4 字节抠出并落盘缓存。随后起一个独立视频守护进程，走共享内存传帧， 再上 GL 纹理。这一绕避开了三个麻烦，比预想省心。

素材兜底回退

粒子预设的纹理不在壁纸包里，回退去读 WE 安装目录的素材。逆向兼容要兼容 到「对方产品目录」这一层，说的就是这种回退。

格式读通了，画面还得经得起对质。像不像，肉眼说了算。

三、与官方渲染逐像素对质

渲染要到像素级才算数：像还是糊，肉眼看得见。最磨人的是多 pass 反复尝试， 改一版，跑一版，多次尝试才匹配官方输出。

光晕效果（Godrays）在片元着色器里逼近官方：24 步 raycast，加噪声抖动与 距离衰减。另一类是字段名与含义不符。sequencemultiplier 在这份素材里是 帧率，不是乘数。模糊半径则藏在 blurprecise 的 scale 里。

这类「名字误导人」的事实，靠实证，不靠文档，只能逐条钉死。

四、与 plasmashell 硬约束共存

KDE 的 plasmashell 进程硬编码 --disable-gpu。后果有两条：

  • WebGL 壁纸全黑。
  • 软件渲染回退（SwiftShader）直接崩溃，记录在 KDE 讨论区 #15478。

这条约束逼插件在所有 GPU 路径上自证：不依赖事件循环外的 GPU。它还逼出了 免注销热重载：配置经 KConfig 的 _ReloadCount 机制改完即生效。

开发期不用反复注销登录，调试着色器时价值巨大。

五、用 bundle 契约管住两端

图形管线没法在纯 C++ 里闭门造车。解包场景、预计算 77 个渲染层与 NDC（归一化设备坐标）变换矩阵，都放到离线侧完成。这一步交给 Python 的 moderngl（OpenGL 绑定库）来做。

烘焙产物是一份 scene_bundle.bin，C++ 侧消费的正是同一份 bundle。 契约一句话：scene_bundle.bin 是唯一契约。Python 与 C++ 不共享任何 运行时状态，只共享这一份文件。

事实只存一处，两端都从它读。契约除此之外，没有第二条。

六、沉淀百余条 lesson 笔记

全程沉淀了一套编号分卷的 lesson（经验条目）笔记，百余条按阶段分区，收成三类。

  • 格式逆向事实：对象没有 type 字段，sequencemultiplier 其实是帧率。
  • 平台坑：QSGRenderNode 层级规则、sync() 深拷贝重置粒子、QML 缓存失效。
  • 工程纪律：先验环境再写码、一次只改一件事、热重载免注销。

这些笔记既是开发日志，也是写给未来的自己与合作者的领域规范。 这套习惯的内核：每条教训都内联成规范。

收尾：价值在三线闭环

这个插件的价值不在代码量，而在三件事的完整闭环：字节级格式逆向、 跨进程跨语言的渲染、与桌面硬约束共存。做完这一趟，逆向私有格式、 设计跨语言契约、在别人定死的运行时里干活，都成了有完整方法论支撑的能力。

起点是那个决定：不调用 WE 运行时，只读它的格式。仓库以 GPLv2+ 协议开源： Matt-qwq/-plasma-wallpaper-engine

终点回到开篇那句话：逆向兼容不是偷代码，是读懂格式后做自己的实现。
